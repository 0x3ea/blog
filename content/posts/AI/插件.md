# acp

 Agent Client Protocol（智能体客户端协议）
 
以前编辑器需要为每个ai 助手开发插件,工作量很大,acp就是为了解决这个问题而诞生的

编辑器只需实现一次 ACP，就能接入所有支持该协议的 AI 助手。

AI 助手只需实现一次 ACP，就能在所有支持该协议的编辑器中使用。

# mcp

 Model Context Protocol（模型上下文协议）

 以前的ai只能通过用户的文本来获得信息,而mcp则可以让ai助手获取到当前环境中的上下文信息(数据库,文件系统)

 MCP 采用 客户端-服务器架构

 MCP 主机 (Host)：需要获取外部数据的 AI 应用，比如ide/ai客户端。
 
 MCP 客户端 (Client)：它在主机内部，负责与 MCP 服务器通信。
 
 MCP 服务器 (Server)：这是一个轻量级的服务程序，它通过 MCP 协议向外界暴露特定的功能。例如，一个“GitHub MCP 服务器”可以让 AI 读取仓库代码，一个“数据库 MCP 服务器”可以让 AI 执行 SQL 查询。
