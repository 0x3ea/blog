# TUI

命令行界面(Command-Line Interface)

无状态,基于行,比如linux bash,sh

# CLI

文本用户界面(Text-based User Interface)

用字符在终端绘制类似图形界面的布局,开源`全屏`操作,通过方向键(鼠标)选择项目

有状态(界面会刷新变化) top /htop vim

# GUI

图形用户界面(Graphical User Interface)

用窗口、图标、按钮、鼠标指针来交互的界面
